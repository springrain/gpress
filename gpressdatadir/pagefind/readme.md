# 下载 
下载[pagefind_extended](https://github.com/Pagefind/pagefind/releases) 的最新版本,目前的版本是 v1.6.0   
默认有四个平台,请赋予可执行权限:  
- pagefind_extended-amd64-windows.exe
- pagefind_extended-amd64-linux
- pagefind_extended-arm64-linux
- pagefind_extended-arm64-darwin

# 把search.html模板中 修改为 `{{ $searchMode := 1 }}`

# 在后台管理,点击`刷新站点`,生成pagefind索引
